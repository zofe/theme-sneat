# Changelog

## [0.1.5] - 2026-09-16

- Rebuilt on rapyd-admin 9.13.3: row separators and text utilities of the module views.

## [0.1.4] - 2026-09-15

- Dropdowns: the active item is white on the primary colour (it was primary on primary), hover is a primary tint.
- Vertical menu: visible hover (primary tint) and a readable active item in dark mode.

## [0.1.3] - 2026-09-15

- Menu toggle: the chevron is centred in the round button; the brand keeps its initial when the menu is collapsed to icons.

## [0.1.2] - 2026-09-15

- The guest Login link of the admin navbar follows `RAPYD_AUTH_LINKS`.

## [0.1.1] - 2026-09-15

- Theme picker honours `rapyd.theme_picker` (rapyd-admin 9.13.1).

## [0.1.0] - 2026-09-15

First version: Sneat free 3.0.0 (vertical menu) as a rapyd-admin theme, with dark mode, runtime palette, theme picker
and the rpd navigation components rendered as Sneat menu items.
